# Supplementary data and code

This public repository is the release location for the data, code, trained checkpoints, evaluation scripts, and reproducibility instructions associated with an anonymous 2026 workshop submission.

The complete release package is being prepared for upload. It will include:

- source movies and synchronized electrochemistry;
- preprocessing code and derived arrays;
- fixed split definitions and model configurations;
- training and evaluation code;
- checkpoints used for the reported results;
- figure and table generation scripts;
- environment specifications; and
- explicit code and data licenses.

The package will be accessible without an access request.
